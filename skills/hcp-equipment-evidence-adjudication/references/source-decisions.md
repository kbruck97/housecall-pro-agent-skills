# Editorial source decisions

## Base selection

The source inventory reports one main/tree variant for hcp-equipment-evidence-adjudication. The full source main file was read and its content hash matched the inventory before distillation. The inventory report and manifest were reviewed for privacy, portability, dependency and mode conflicts. No historical case corpus was copied.

## Selected reusable references

Source filenames below are provenance labels, not links to files bundled in this package:

- `react-ui-urls-are-not-job-attachments.md`: retained attachment-container boundaries and rejection of UI assets; discarded the tenant-specific example and job facts.
- `line-item-hydration-fallback.md`: retained the missing-expanded-versus-dedicated distinction; replaced unconditional private-first reads with capability-discovered public reads and explicitly opted-in private parity.
- `exhaustive-class-allowlist-before-equipment-enum.md`: retained allowlist-before-enum and coverage requirements for empty results; removed tenant/case chronology and mandatory private access assumptions.
- `spatial-label-vs-appliance-presence.md`: retained direct appliance-presence versus room-name distinction; does not turn presence into installation.

All selected reference bytes matched entries in the private inventory manifest. Exact source locations and raw evidence remain outside this distributable package.

## Deliberate changes

- Split installed-new, serviced-existing, observed-existing and accessory-event outputs. Generic class evidence can support inventory without satisfying identity-required equipment creation.
- Replaced unconditional completion-date installation assignment with explicit installation evidence or a disclosed, policy-permitted completion proxy. Service, import and manufacture dates are not install dates.
- Retained quantity/serial reconciliation, combi-cabinet uniqueness, explicit component boundaries, unknown side mapping and fresh dedupe checks.
- Replaced case-specific equipment exceptions with a configurable class/component/accessory policy and synthetic tests.
- Removed live endpoint promises, hardcoded taxonomy identifiers, credential/session recovery instructions, probe-write/delete discovery, local tool names and private runtime assumptions.
- Restricted output to read-only recommendations. Named dependencies are prose, not nonexistent universal actions.
- Added explicit partial coverage, blocked claims, field provenance and verification-receipt contracts.

The owner authorized the included RivetFlo-owned material for MIT release. Excluded historical source files and neighboring packages are not licensed by this distribution. Technical validation is recorded in [package validation](package-validation.md).
